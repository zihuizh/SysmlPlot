## 当前优先：展示层升级

| 项 | 说明 |
|---|---|
| 图库框架选型 | 已确定采用图库框架；G6 与 Cytoscape 仍在试验，尚未最终选定 |
| 产物适配层 | 把 `view-product.json` 转成框架数据；框架专有字段不得进入语义产物 |
| 框架内布局 | 在图库框架内按视图类型选择布局，不再扩展 Java 自研布局作为主方案 |
| 节点表现 | 验证嵌套节点、端口、仓格、长文本和不同语义元素的样式 |
| 交互 | 缩放、拖动、选中、聚焦、筛选、关系导航、跨视图切换和大纲搜索 |
| 动画 | 视图切换、展开收起和重排时保持元素可跟踪；避免无意义动画 |
| 导出 | 明确框架画布到 SVG/PNG 的稳定导出路径，并保留现有无头导出作为对照 |
| 展示层测试 | 增加截图或结构断言，覆盖布局、端口、嵌套和主要交互 |
| 大图性能 | 用真实语料验证首帧、重排、缩放和内存占用，定义降级方案 |

## 语义层仍需补齐

| 项 | 说明 |
|---|---|
| Action Flow | 控制节点、守卫和 trigger 尚未实现 |
| State Transition | 状态节点及 trigger/guard/effect 迁移边尚未实现 |
| 端口方向 | 从端口特征读取 `in` / `out` / `inout`，必要时才用连接器端序辅助判断 |
| filter 不确定性 | 条件无法求值时，当前不能区分“排除”与“结果不确定” |
| 诊断去重 | 相同链接错误可能由资源错误和 Xtext validator 重复报告 |
| 隐式元素分类 | `origin` 的判定仍需复核，例如 Documentation 可能被归为 `library` |
| 跨平台确定性 | `getExposedElement()` 顺序目前只在本机验证 |

## 当前阶段 · 展示层升级

**目标**：以稳定的 `view-product.json` 为输入，用图库框架统一实现布局、交互和动画。

已经确定：

- 使用图库框架，不继续扩展自研布局系统作为主要方案。
- 视图产物保持语义层，不写入框架专有坐标、样式或交互状态。
- 现有 Java 布局、SVG 和自包含 HTML 保留，用于无头导出、回归对照和兼容。

尚未确定：

- 最终采用哪一个图库框架。G6 与 Cytoscape 的 P0 结果见 `docs/GRAPH-LIB-P0.md`。
- 不同视图类型分别采用什么布局和表现方式。

### 工作顺序

1. 用同一批视图产物继续验证候选框架，重点看端口、嵌套、仓格和大图交互。
2. 定义“视图产物 → 图库数据”的适配层，避免框架细节进入 Java 语义层。
3. 在框架内实现布局、缩放、拖动、选中、聚焦、筛选和视图切换。
4. 增加有意义的过渡动画，保证切换和重排时仍能跟踪元素。
5. 补齐导出、性能和视觉回归，再替换现有交互页的主入口。

### 完成标准

- General、Interconnection 和局部关系视图可由同一展示层打开。
- 端口、嵌套节点、仓格和关系边表达正确。
- 布局、交互和动画由图库框架执行，Java 侧不再新增展示算法。
- 中等规模模型操作流畅，大图失败时有明确提示或降级方案。
- SVG/PNG 导出和当前语义回归继续可用。

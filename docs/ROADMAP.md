## 当前阶段 · 展示层升级

**目标**：以稳定的 `view-product.json` 为输入，用图库框架统一实现布局、交互和动画。

已经确定：

- 使用图库框架，不继续扩展自研布局系统作为主要方案。
- 视图产物保持语义层，不写入框架专有坐标、样式或交互状态。
- 现有 Java 布局、SVG 和自包含 HTML 保留，用于无头导出、回归对照和兼容。
- **采用 G6 5.1.1 作为展示层框架**，Cytoscape 3.34.3 保留为体积敏感的备选（依据
  `docs/GRAPH-LIB-P1.md`：端口原生、combo 能吃原生布局、仓格用内置 html 节点零扩展）。
- 判断展示层的标准只有两条：**排布易读**、**语义表达正确**（端口、嵌套、仓格、边）。
  不要求与现有 Java SVG 布局一致。

尚未确定：

- 不同视图类型分别采用什么布局与表现方式（P1 已给出候选与实测，默认值仍需随视图类型收敛）。
- 框架画布到 SVG/PNG 的稳定导出路径。

### 完成标准

- General、Interconnection 和局部关系视图可由同一展示层打开。
- 端口、嵌套节点、仓格和关系边表达正确。
- 布局、交互和动画由图库框架执行，Java 侧不再新增展示算法。
- 中等规模模型操作流畅，大图失败时有明确提示或降级方案。
- SVG/PNG 导出和当前语义回归继续可用。
